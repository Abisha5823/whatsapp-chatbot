# WhatsApp AI Chatbot System

## 🚀 Production-level WhatsApp automation with RAG, lead generation, and booking

### Features
- 🤖 **RAG-based AI** - Answers from business PDFs
- 🗣️ **Multi-language** - Tamil, Tanglish, English
- 📋 **Lead Generation** - Automatic lead collection & Google Sheets sync
- 📅 **Booking System** - Appointment scheduling with availability
- 🔔 **Notifications** - Email & WhatsApp alerts to owner
- 👤 **Human Handoff** - Transfer to agent when needed
- 🎤 **Voice Notes** - Speech-to-text support

### Tech Stack
- **Backend**: FastAPI (Python)
- **Database**: MongoDB Atlas
- **AI**: Google Gemini / OpenAI
- **RAG**: LangChain + FAISS
- **WhatsApp**: Meta Cloud API
- **Deployment**: Render / Vercel
